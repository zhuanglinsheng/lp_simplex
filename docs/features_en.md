# Algorithm and capability index

[简体中文](./features.md) | English | [Documentation](./README_en.md) | [Algorithms](./algorithm/README_en.md)

Find capabilities by admission, input/output and implementation entry. Only public algorithms are selected through `Options.algorithm`; internal roles, representations and backends are not additional public algorithms. Test entries indicate coverage, not performance guarantees.

## Public solver modes

| Name and purpose | Caller and activation | Input → output | Limits | Implementation | Tests |
| --- | --- | --- | --- | --- | --- |
| TABLEAU: two-phase primal simplex | Public selection; AUTO recovery for small models | LP → point and status | Dense representation; no exported dual multipliers | [tableau_solver](../src/tableau/simplex_tableau_solver.c) | [result_contract](../test/test_result_contract.c) |
| DUAL_REVISED: sparse dual revised simplex | Public selection; AUTO primary and final recovery | LP, optional internal basis hint → point, status, diagnostics | Hints require rebuilding/auditing; no public warm-start argument | [dual](../src/dual/simplex_dual.c) | [regressions](../test/test_regressions.c) |
| PAN_BDA: dynamic deficient-basis optimization | Public selection; internal feasible-seed entry | LP, optional internal seed → point, status, diagnostics | Standard form by default; native bounds and other variants use internal routes or manual controls | [pan](../src/bda/simplex_pan.c) | [pan](../test/test_pan.c), [warmstart](../test/test_pan_warmstart.c) |
| AUTO: algorithm orchestration | Public selection | LP → result and retained point within cumulative budget | Heuristic selection; no fastest-route guarantee | [auto](../src/core/simplex_auto.c) | [auto_policy](../test/test_auto_policy.c), [auto_flow](../test/test_auto_flow.c) |
