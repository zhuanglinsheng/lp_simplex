# BDA 阶段契约

简体中文 | [English](./pan-services_en.md) | [文档](./README.md) | [AUTO 调度](./auto-policy.md)

BDA 拥有自己的调用状态。NNLS、PDHG、切锥、恢复和对偶修整是内部角色；标准形/原生界属于表示，显式/隐式属于 oracle 实现，QR 属于数值后端。

[service](../src/bda/simplex_pan_service.c) 统一适配调用，[types](../src/bda/simplex_pan_service_types.h) 定义角色和产出。BDA 主循环决定何时调用，子过程负责局部迭代和数值审核；跨算法顺序仍由 AUTO 决定。

## 服务与产出权限

| 服务 | 输入与适用条件 | 允许的产出 | 授权与退出 |
| --- | --- | --- | --- |
| `nnls-initialize` | 等式表示、活动基及容差；尚无初始点 | 当前表示的非负等式可行点 | 父剩余工作；handoff、预算、数值、资源或经验证的当前模型不可行 |
| `dual-feasibility` | 稳定的输入 LP 和已解析配置；需要初始点 | 输入空间的可行点 | 剩余工作；Dual 相对计数转换为父累计计数 |
| `pdhg-advance` | 原生界点/乘子，非零行稀疏模型 | 经审核的可行改进点，或 native KKT | 请求与剩余工作取小；预算、停滞、handoff、认证、数值或资源 |
| `cone-direction` | 派生切锥、活动基、自由变量掩码 | 方向提案、驻点残差或经接受函数审核的方向 | 剩余工作；成功角色为 handoff，保留实际 oracle 和失败原因 |
| `feasibility-restore` | 标准形/原生界点及目标上限 | 对应表示的可行点，不含乘子/基/LP 分类 | 剩余工作；handoff、not-applicable、预算、数值或资源 |
| `dual-refine` | 当前表示、点及乘子 | 经过检验的乘子 | `dual_polish_iterations` 与剩余工作取小 |
| `direction-predict` | 当前表示、点/乘子、自由掩码及可选接受函数 | 经过检验的方向或乘子 | 显式请求或 `first_order_iterations` 与剩余工作取小 |
| `native-face-recovery` | 原生界点/乘子和局部请求 owner；启动、低进展或乘子搜索后 | 内部面调整，不授予可复用点或 KKT | 保留零迭代计费；调整、无变化、精确跳过或排序资源拒绝 |

近似点、NNLS 可行点、辅助驻点和检验过的方向都不能单独宣称输入 LP 最优。普通 NNLS 的不可行出口须独立验证 `Az=b, z>=0` 的分离证据；无进入列、溢出、符号不确定或证据分配失败不构成证明。混合 NNLS 的驻点仅供方向算法使用。

零预算不授权额外迭代。标准形恢复若已无需修复，可零工作返回 not-applicable 且无新产出；零行 PDHG 不适用。零迭代的面检查不等于零 CPU 成本。

## 身份与授权

每次 BDA 调用创建局部 `PanServiceContext`，固定输入完整身份和根作用域。标准形、原生界、切锥及中心化辅助表示各自绑定或显式派生；同维度不是同模型。

`begin` 捕获工作表示的矩阵、范数、映射、缩放/平移及目标绑定，授权 `min(requested, limit-before)`。原生适配器还固定输入对象和界数组。`finish` 核对输入/表示身份、基归属、累计计数及产出角色。源模型和映射须在借用期内存活且不可变；原地修改需标记 revision，元数据检查不扫描系数内容。

坏计数按授权末端保守计费，保留原始报告；身份或权限契约失败撤销输出，并设置调用上下文的粘性失败标记，主入口提交前再次检查。普通预算、资源或数值失败不会自动变成契约失败。可选快照拒绝与必需工作区拒绝分别处理，详见[资源政策](./numerical-policy.md)。

`Outcome` 只描述一次调用，不拥有点/乘子/基数组，也不是跨模型检查点。Dual 可行性调用使用稳定输入身份，不能把栈上的只读外壳当成失败请求身份。

## 运行状态与履历

上下文和帧承载保护，Outcome 描述产出，StageReport/执行事件只提供诊断。履历关闭、容量满或同址重置不改变数学资格。跨回调引用绑定上下文和 token，过期时出处归零。

PDHG 内恢复的父调用为本次 PDHG；两者共享一个累计计数，恢复工作已包含在 PDHG 汇总中，不能跨服务相加。对偶原始相对工作与适配后的累计工作分别保留。

触发原因来自实际观察：标准形 trial 残差标记 `primal-margin`；PDHG 停滞标记 `pdhg-stagnation`；面机会区分首次切锥步之前、低进展、实际乘子搜索之后。触发、工作位置、度量版本、点源和数值产出不从“最近事件”推断。观察事件不额外收费，也不是数学结果。

## 恢复与重复准入

| 机制 | 消费状态与限制 |
| --- | --- |
| NNLS | 残差、活基和 blocked 集共同推进；因子拒绝屏蔽当前列，支撑变化后可重开。成功插入/块插入消费工作，无进入列须按所属模型角色审核。 |
| 显式/隐式切锥 | 支撑删除、blocked 列、隐式重复模式检查和已收费方向步推进状态；重开冻结面、改用一阶/NNLS或缩紧 inner tolerance 改变请求，内层重试次数有限。 |
| 一阶/CG/Newton | 更新、单调重启和 CG 子步共享结束位置；有限线搜索属于数值保护，不重新进入 AUTO。方向与乘子仍须审核。 |
| 标准形恢复 | 以新 trial 和 saved 成本上限为输入。失败后回滚并换方法、缩紧容差或退出；接受前复算残差、成本及非零点变化。 |
| 原生压缩/认证修整 | 压缩失败回滚，再重建种子进入通常切锥；乘子投影失败回滚。它们不导出可复用检查点。 |
| PDHG 恢复 | 完整窗口停滞、点仍需修复、目标低于上限且有余量；每次尝试的物理残差须严格小于上次的一半。成功和失败均更新基线，普通/权重重启不清除此基线。 |
| 原生面恢复 | 仅实际无变化请求可记忆；精确比较模型/表示、点、乘子和容差。变化重新执行；记忆不足保留未知，不冒充已执行。 |

面请求只保存最近一条，快照上限 4 MiB。排序拒绝为资源退出；快照拒绝可保留已经完成的无变化检查，但不形成已知请求。owner 必须先于盒表示销毁，输入原地修改前须清除。具体常量和误差尺度见[数值政策](./numerical-policy.md)。

## 实际入口与测试

完整求解使用 `simplex_pan_solve_configured`；原生界内核使用 `simplex_pan_bounded_solve_certified_configured`。PDHG、恢复和一阶数值过程由服务调用唯一的 `*_configured_reported` 入口。配置来自根快照或 AUTO 适配器，私有入口不承诺 ABI 稳定性。

`test_pan_services` 检查角色、嵌套授权、坏计数、身份和履历寿命；`test_pan_recovery`、`test_pdhg_restore_trigger`、`test_pan_face_recovery`、`test_pan_face_service` 检查实际恢复与失败消费。数学推导见[算法文集](./algorithm/README.md)。
