# 数值与资源政策

简体中文 | [English](./numerical-policy_en.md) | [参数与结果](./parameters.md) | [文档](./README.md)

公开容差描述用户要求；内部政策描述搜索、稳定性和资源选择。二者不能互换。内部常量集中于 [src/common/policy](../src/common/policy)，完整默认值以源码为准；修改政策时须说明量纲、作用范围、保守失败行为和验证依据。

## 关键默认值及单位

| 项目 | 默认值 | 解释 |
| --- | --- | --- |
| 原始 / 对偶 / 主元容差 | `1e-7 / 1e-7 / 1e-9` | 不同量纲，分别用于可行性、搜索及主元/判秩 |
| 工作预算 | 手动 `100000`，AUTO `300000` | 迭代工作，不是时间；以公开默认选项为准 |
| 进度观察 / 通知 | `128` 工作 / `5` CPU 秒 | 确定性采样与界面节流分开；通知间隔不是超时 |
| 基相对稳定主元 / 绝对底限 | `1e-7 / 1e-14` | 弱更新请求重分解；不证明奇异或不可行 |
| 内部 LU 零主元阈值 | `1e-13` | 消元/更新保护，与用户主元容差不同 |
| Markowitz / KLU 主元偏好 | `.1 / .1` | 后端各自的选择政策，不是最终精度 |
| 基 / FT 更新长度 | `512 / 512` | 有限链保护，不单独保证误差 |
| compact 残差 / 精化 / 审查周期 | `1e-11 / 2 / 32` | 内部相对残差与有限纠正；terminal 精化最多 `3` 次 |
| Dual 初次观察量 | `8 * 128 = 1024` 工作 | 续跑与让出的观察机会，非固定求解期限 |
| Dual crash 尝试上限 | `min(INT_MAX, 4*variables+rows)` | 先检查再乘加；初始化交换不扩充主迭代授权 |
| Dual 无主元重启上限 | 饱和的 `4*rows+64` | 阻止零迭代重启循环；与主元工作独立 |
| PDHG 观察 / 停滞窗口 | `128 / 8192` 步 | 同度量历史最好值的累计改善需超过 `1%` |
| PDHG 步长收缩 | `.99` | 对角预条件范数界的安全留量 |
| 一阶回溯 / 次数 / CG 上限 | `.5 / 20 / 256` | 局部数值提案的有限成本 |

这些值是明确的经验或数值政策。局部 `16/32/64 * DBL_EPSILON` 留量须连同绝对和、运算维数及误差尺度理解，不能合并成一个全局 epsilon。绝对 LU 底限、规模门槛和部分收益底限仍有启发式性质；修改需要条件、误差或性能证据。

## 认证与尺度

### Tableau

人工基清理按行尺度和主元容差检查非零主元；仅当真实列和 RHS 全部恰好为零时保留冗余行。无法可靠消除或操作后出现非有限值时返回精度失败，不擦除方程、不推断不可行。Phase I 的非有限目标也不构成不可行证明。Bland 使用请求容差和最小合格索引，不使用十进制递减阈值。

### BDA 与 PDHG

低进展收益阈值使用 `max(64*DBL_EPSILON, units*dual_tolerance) * max(|旧无常数成本|, sum|c_j*x_j|)`；普通、扩面、缩面的 units 分别为 `100/10/1000`。目标常数不参与；这不保证任意变量变换下浮点路径相同。

PDHG 接纳点同时检查绝对原始残差和逐行尺度：`|b_i-A_i*x| <= primal_tolerance*(|b_i|+sum_j |A_ij|*max(1,|x_j|))`。加权 merit 的历史基线在度量改变时重置，普通重启不抹去历史最好值。恢复机会要求停滞、剩余授权、目标上限及相对上次尝试至少减半的物理残差，见[阶段契约](./pan-services.md)。

交接 gap 按实际界计算对偶下确界：非零约化成本所需的界不存在时，下确界无穷；零约化成本贡献为零。相对 gap 用 `max(|primal|,|dual|)` 归一化，相等时单独返回零。它只是交接诊断，成功仍需原生 KKT。

### 乘子的直接 QR 恢复

标准形基重建后仍不能审核乘子时，[独立 QR 模块](../src/bda/simplex_pan_basis_qr.c)用 DGELSY 求当前原始基方程，不形成正规方程。`RCOND=DBL_EPSILON` 分辨算术秩；不把用户主元阈值再次作为全局条件数截断。要求满行秩、有限解及原始基残差；后续检验数、可行性和间隙认证不变。只有成功才写乘子，失败不改输出，不改变基或 LP 工作授权。

### 输入、缩放和预解

公开输入拒绝有效数值字段中的 NaN/无穷和不合法稀疏布局；未使用的界端点不参与检查。MPS 数字必须完整解析，拒绝截断、尾部垃圾、范围展开溢出及非有限数，不能用零替代坏输入。

平行行约化须确认原始系数的精确比例关系；近似相等不能授权矛盾分类。缩放要求有限且可逆，失败时保留原坐标输入。恢复记录先准备再发布，逆序重放依赖；最终求解仍按原模型审核。

## 存储与失败边界

| 所有者 / 可选工作区 | 上限或提交规则 |
| --- | --- |
| AUTO 稠密模型 / 转换 | `32 / 64 MiB`；适配准入失败跳过路线 |
| cover 固定自有工作区 | `256 MiB`；包含点暂存及布局位图，不含所有委托分解存储 |
| BDA 直接 QR | `32 MiB`，含新增矩阵、索引及 LAPACK scratch |
| 精确基失败快照 / 原生面请求 | 各 `4 MiB`；保存拒绝只失去可选记忆 |
| dominance 索引 | `32 MiB` 峰值与 `64*(nnz+m+n)` 搜索工作；拒绝禁用可选搜索 |
| 不可行证据 | rank `128`、bits `8192`；无法确认不授予分类 |
| 缩放 | `4` 次，指数范围 `[-48,48]`；非可逆转换回退 |

数组检查覆盖元素数、填充、乘加字节数和后端整数范围，随后才分配。必需模型/启动存储失败返回 `MemoryAllocError`；可选存储失败只撤销该能力，不能伪造数值或数学失败。

- **模型与表示：** sparse cache、代换记录和压缩先准备所有必要存储，再发布新布局；失败保留已提交输入并清理暂存。
- **LU/基：** 完整分解失败撤销数值有效性；资源类别与奇异分开。FT/eta 在修改已提交因子前准备扩容，失败保持此前可解状态。基导入必须重新分解和分类。
- **QR：** 动态追加在破坏旧列前准备容量及临时行；追加失败保留此前列的数学可用性。该事务保证不能扩大到所有删除、交换或重载操作。
- **预解：** 启动工作区和约化输出分配失败清理所有者；journal 的代换依赖逆序恢复。dominance 固定列后，下一队列 epoch 执行消元和记录。

局部门槛不是总 RSS，工作预算不是 CPU 截止。维数/窄地址空间探针不等同于运行巨型 LP 或原生 32 位验证。部署隔离、支持平台与依赖见[项目说明](../README.md#交付与兼容性边界)。

## 配置与复现

正式入口固定默认值；只有显式实验入口捕获数值环境，之后使用根快照。存在型开关的字符串 `0` 仍表示存在；整数工作设置拒绝负数/坏格式，正溢出饱和；权重须完整、有限且在范围内。详见[配置边界](./runtime-configuration.md)。

比较时记录源码、构建/后端、公开选项、模型、线程设置、运行记录和解审核。性能方法由[数据说明](../data/README.md)维护，历史结果与缺陷修复由[开发记录](./development/README.md)维护。
